# 개인 홈페이지

파일 3개(`index.html`, `style.css`, `script.js`)로 된 한 페이지 사이트입니다. 빌드 과정이 없습니다.

## 내용 채우기
`index.html`에서 `[채울 곳: …]`을 모두 찾아 바꿉니다. 이메일·GitHub는 화면 글자와 `href="…"` 안의 주소를 둘 다 바꿔야 합니다. 채우지 않은 자리는 화면에서 옅은 초록 배경으로 보입니다.

## GitHub Pages에 올리기
1. GitHub에서 새 저장소를 만듭니다. 이름을 `아이디.github.io`로 하면 주소가 `https://아이디.github.io`가 됩니다.
2. 저장소 화면의 **Add file → Upload files**로 이 폴더의 파일 4개를 올리고 **Commit changes**를 누릅니다.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 두고 저장합니다.
4. 1~2분 뒤 위 주소로 접속합니다.
